Layer templates can carry an intro and outro. Pick them in the template editor's new Intro & outro block (Clip's own, None or a library video or image); applying the template sets them on the clips as their own choice, in the same step as the layers, and new clips of a project that uses the template get them too. Save as template keeps the clip's intro and outro. Also in the `save_layer_template` / `update_layer_template` MCP tools (`bumpers`) and `reelsaw templates set --intro / --outro`.
