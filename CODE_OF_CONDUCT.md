# Code of conduct

Reelsaw adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
The full text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful, assume good faith, no harassment, no personal attacks. It applies in
issues, pull requests, discussions and any other project space.

## Reporting

Use GitHub's **Report content** on the comment, issue or discussion, which reaches the
maintainers privately. Reports are kept confidential and answered within five working days.

## Enforcement

The maintainers may edit or remove content, and warn, temporarily block or ban a participant,
following the Covenant's enforcement guidelines.
